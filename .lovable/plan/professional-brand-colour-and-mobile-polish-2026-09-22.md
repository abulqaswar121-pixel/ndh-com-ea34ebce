# Professional brand colour and mobile polish

## Recommended direction
Use a **Graphite + Signal Cyan** system: near-black backgrounds, clean white text, electric cyan for identity and active states, with a restrained cobalt secondary accent. It keeps the sharp technology feel while adding memorable colour and avoiding the current flat monochrome look.

## What will change
- Refine the existing NDH logo into a cleaner transparent logo that blends naturally into dark and light placements, using the website’s new graphite, white, cyan and cobalt palette.
- Apply the same palette consistently to key actions, active states, focus rings, labels and selected details without changing the current page layouts.
- Remove the “Navigate” label from the phone menu and make the panel fit within the visible phone height, with internal scrolling so “Start a project” is always fully reachable.
- Upgrade the customer-service launcher to a polished animated AI assistant symbol with a subtle live-status motion, while respecting reduced-motion settings.
- Check key public pages and both phone and laptop sizes for clipped buttons, weak contrast, missing visual hierarchy and sideways overflow.

## Technical details
- Keep all colours as shared website tokens so the logo and interface remain consistent.
- Preserve the current content, links, page structure and customer-service behaviour.
- Use a transparent logo asset rather than a square image background.
- Use the approved AI chat building blocks where the chat surface is touched, without changing its API behaviour.
