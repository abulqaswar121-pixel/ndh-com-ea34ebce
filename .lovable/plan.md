# NDH connected-node brand system

## Direction
Adopt the supplied **Connected Node Matrix** as NDH’s one master symbol across Agency, Academy, portals, the AI assistant, browser icon, and static brand exports. Recreate the symbol as a clean scalable graphic rather than embedding the uploaded checkerboard image.

Use **Inter** throughout and keep the navbar lockup compact: animated node-matrix icon plus “NDH”. The full “Najeeb Digital Hub” name remains available in page titles, footer copy, and brand metadata.

## Implementation
- Build one reusable master logo with the exact node structure, purple-to-magenta linked lines, and cyan nodes shown in the supplied reference.
- Add independently staggered 3–4 second cyan-node glow pulses and a slow 8–12 second gradient movement using opacity/filter and paint animation only.
- Provide a static reduced-motion state with the same glow and colours.
- Replace current logo instances in the public navbar, phone menu, footer, and AI assistant with this same master mark—no Agency or Academy variants.
- Apply the exact tokens site-wide:
  - background `#0A1A30`
  - gradient start `#8A2BE2`
  - gradient end `#FF007F`
  - cyan `#22D3EE`
  - text `#FFFFFF`
- Use the gradient selectively for the master mark and key actions; use cyan for nodes, active states, focus rings, and small status details. This keeps the site professional rather than covering every surface in gradients.
- Switch the site typography to Inter. Keep body copy at weights 400–500 and retain wide uppercase spacing for small sub-headings.
- Create static, clean versions from the same mark for the favicon, app icon, and social preview image. Preserve existing social-preview content while updating its brand treatment.
- Keep the current page layouts, copy, images, links, portals, and business behaviour unchanged.

## Verification
- Check the homepage, Agency, Academy, work pages, sign-in screens, and each portal at phone and laptop sizes.
- Confirm the master mark is identical everywhere, animations are smooth, reduced-motion disables pulsing, contrast remains readable, and no logo or text is clipped.
- Confirm the favicon and social preview use the static mark and the preview builds without errors.

## Design recommendation
Keep the background predominantly deep navy and reserve the purple-magenta gradient for identity moments and primary emphasis. A faint node/circuit line texture may appear only in large dark feature areas at very low contrast; avoid adding it behind body copy or portal data.
