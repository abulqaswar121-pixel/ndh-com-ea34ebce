# Hague Export client walkthrough

A visual handover guide for <https://hague-export.lovable.app>.

- **Shareable PDF:** [Hague-Export-Client-Walkthrough.pdf](./Hague-Export-Client-Walkthrough.pdf)
- **Interactive web version:** [index.html](./index.html)
- **Screenshot set:** [`images/`](./images/)

The guide contains 32 live website screenshots covering the public marketplace, buyer RFQ journey, exporter workspace, verification tools and Kemi AI support. Captions use short, client-friendly Nigerian English.

> Phase 1 note: marketplace data is illustrative. Live payments, escrow, logistics bookings and binding contracts are not processed in the preview.
